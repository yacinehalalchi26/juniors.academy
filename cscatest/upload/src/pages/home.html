Questions

Is this the official CSCA?

No. cscatest.org is an independent practice platform run by Juniors Academy. Official registration and exams are only at csca.cn, and practice scores can't be used for admission.

Which test should I start with?

Start with a quick test to see where you stand in 15 minutes. Then take a module test for an accurate score, and a full exam to practise your stamina before exam day.

Do the questions change?

Yes. Every test is built from a large question bank. Questions are picked by topic in the same proportions as the syllabus, and questions you've already seen are avoided, so each attempt is new.

Why was my test cancelled?

If there's no activity for 10 minutes, the test is cancelled and isn't scored. This keeps practice realistic. You can start a new test straight away.
